## 可见事实与商品

- 观察：newsletter 公开创业过程和产品结果，官网把 Marc 的多个产品、教程和 ShipFast 相连。收入与读者数均为作者自称。

- 观察：页面现价 Starter $199、All-in $249、ShipFast+CodeFast $299；一次付费可多项目用。官网要求使用者熟悉 React/NextJS。

- 观察：文档公开展示 GitHub 克隆、环境配置和 UI/支付等模块；没有购买私有代码。

## 引流、承接到交付的路径

- 环节：产品实践/内容 → 个人组合页或 ShipFast → 代码与文档说明；状态：公开一方入口已读

- 环节：选择三个计划 → Get ShipFast；另有 PayPal 手动支付说明；状态：在线按钮未取得可读结账；FAQ 给金额和付款后提交 GitHub 用户名的流程，未支付/联系

- 环节：获得代码仓库访问 → 按文档部署 → 按计划支持；状态：仅公开承诺，未核代码、访问或支持质量

- 商品：USD 249 / All-in 一次性；对照价 349；各计划被划除功能的静态抽取不清，不强行归属社群等权益

## 谁可能付钱、为什么信任（待验证假设）

- 同类身份与产品记录可能使模板更可信；没有控制组能证明人设带来溢价，功能与社群同样可能驱动购买。

## 可复制性与本人能力门槛

**learnable_processes：** 免费文档与可跑样例先暴露使用门槛；将重复工序做成模板；记录修复/版本和真实用户问题
