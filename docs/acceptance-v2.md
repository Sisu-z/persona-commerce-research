# B v2 验收：匿名高势能人设与真实成交的联系

## 不再把“20个有收费链接的专家”当成任务完成

评估的是 **精准匹配度、具体内容证据、客户推断逻辑、真实商品与路径、交易强度、可复制性** 六个维度。脚本、文件数量、链接和哈希只验资料完整性，不验商业结论。

### G1 样本匹配
主体确有持续经营的角色/品牌形象，并尽可能满足匿名、低露脸或非实名头衔背书；有可见商品/变现入口；且研究了多个实际内容。名人/大型实名IP可做对照，不能列成核心匿名样本。

### G2 形象的作用机制
写明具体图文/视觉/语言证据，消费者可能从中推断什么、这与其购买顾虑如何相关。**形象暗示是观察，受众信念是待验证假说**；不能凭漂亮页面认定高信任或溢价。

### G3 完整商业链
能找到这个账号在卖的真实商品/服务，以及内容到商店/咨询或支付前的一段可复核路径；写清交付者、商品完整范围、价格和售后。看不见买后就不写成交完成。

### G4 相近条件的对照
比较同品类普通或失败对照，至少解释三种替代原因：商品本身、价格或履约差异、投放/既有受众/渠道资源。因果不明时不宣称“包装创造高溢价”。

### G5 新人可复制
明确哪些形象和内容资产可以重新设计、哪些资历/场景/产品/合作供给不能凭空获得；提出具体的产品×客户×角色组合与吸客入口，不能只说“打造高端人设”。

### G6 可测试的行动设计
用户认可并有A的产品或真实需求依据后，给出第一组定位/内容/商品承接/指标/成本/停止条件。仅发布、咨询、付款与售后实测需追加授权；不得拿未发布脚本当真实转化。

## 阶段性成果

- **第一检查点**：3–5个合格中国商业号，至少有内容、商品和公开受众互动的实看链；各有普通/替代对照。用户确认是否仍是自己想研究的人设。
- **第二检查点**：约10–15个合格对象覆盖至少三种不同商品/获客方式；不少于3个按模板深拆，包含至少一个失败/弱成交信号对照。若平台封闭限制无法达到，明确请求用户帮助，不用海外名人补数。
- **第三检查点**：写出2–3种能对应真实客户疑虑的形象变现机制，并与A交叉出1–2个可测试模型；无A产品时暂停具体起号方案，不会强行推卖课。

**没有观察到付款、价格接受或独立买家理由，不能说人设已证实带来溢价。** 但可以买前路径、真实售价和独立公开反馈提出逐渐增强的假说，不须假装只有审计账本才值得研究。

## 反向质检清单

- 我们是否主要研究了不露脸的商人/工作室，而非职业名人？
- 实际看过至少数篇内容和图片，还是只是主页/价目表？
- 哪种包装线索让哪一类买家推测出什么，证据在哪里？
- 有没有真正挂卖的产品、可见买方行为和获客入口？
- “卖得贵”是否可能只是服务本身更好或流量更大？
- 为什么这个新人能维持角色与交付？哪里会露出承诺无法兑现的矛盾？
- 即使流量来了，他最终是否拥有客户、产品或收益权？

回答不了且无下一步核查计划的，只能列线索，不得算完成案例。按里程碑请用户验收，不能只在本库内部宣布成功。
