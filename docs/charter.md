# B 项目宪章 v2：人设是可设计的商业转化资产

## 一、目标不是做“真实自我分享”的博主

研究和未来设计的对象是**围绕特定客群与商品，系统经营出来的商业角色/品牌人格**。一个账号可长期保持不露脸、非实名、独立品牌身份，也可以与用户其他账号完全不同定位。研究重心是文案、照片/画面、视觉审美、表达风格、知识密度、场景暗示、关系感、可见作品等如何构成一致的形象，促使受众**自行推断**账号的专业性、资源和地位，从而影响购买意愿。

不得因账号不展示真实姓名、学历或日常生活就将其排除；也**不得把“分享真实经历、先积累粉丝、未来再想卖什么”强加为标准路线**。

研究时应明确区分：商业表达的合理设计和匿名保护；受众根据线索自行产生的印象；账号作出的事实声明。分析可以覆盖富有戏剧性或强暗示性的人设，但不能把伪造订单、财力、认证、合作与客户评价当成可持续的方法。关键不是道德评论，而是成交核验、平台约束与实际履约风险。

## 二、把“产品定位还是客户画像先行”变成决策方法

若已发现有实际付款需求的商品：**商品/使用场景 → 购买者的动机和疑虑 → 他信任什么角色 → 人设与内容 → 流量、承接、订单**。

若先发现高价值且聚集度高的特定客群：**客群需求/消费情境 → 可满足的商品或服务 → 能承接信任的角色 → 同样的成交链**。

若先发现异常有效的人设号：先追它实卖什么、谁买、购买路径，交给A核利润和进入条件；不从账号调性自行臆造市场需求。

客户画像首先写**付费情境、预算、判断依据、风险感、使用替代**，年龄性别/收入仅在有证据时补充。角色设计不是“所有人觉得你是大佬”，而是**会付费的那群人，为什么愿意相信这类卖方并向他付款**。

## 三、研究重点

一、**账号怎样传达高势能而不必显式自夸**：内容选题与信息密度、用语口吻、作品/样品、环境/道具/审美、频繁出现的客户问题、稀缺/筛选/距离感、跨篇叙事一致性。逐条说明“看到的线索”和“可能引发的印象”，不要把心理推断写成既定事实。

二、**账号在哪里得到流量**：小红书检索与推荐、抖音、闲鱼商品搜索、淘宝内容/店铺、跨平台导流、推荐或社群入口。需有具体帖/商品/CTA/评论/账号证据，不能只写“私域闭环”。

三、**卖什么，卖给谁**：具体SKU、定制报价、产品阶梯、价格条件、买前顾虑、售后责任。可先有真实可做原型，再打磨产品；不假设尚不存在的产品已经在售或可交付。

四、**由谁交付以及为何有溢价**：自营、白牌、代理、供应商、团队、平台自动交付分别查。高标价不等于高净利润；成交或平台销售痕迹亦不代表人设造成溢价，必须考虑同规格服务、投放、既有渠道与技能差异。

五、**可复制性**：新人能学习的表达、视觉、内容与产品承接 vs 不能凭空生成的资历、资源、已有受众、真实作品与供应链。分辨账号是否积累客户、品牌、信任或可转移的渠道资产，而不只是接单换工时。

## 四、优先采样哪些账号

**先采中国真实平台上的中小规模匿名、少露脸、弱实名工作室/买手/资源型账号**，尤其是能够展示销售商品、付费咨询或真实订单线索，且对外形象显然经过系统设计的主体。可以涵盖选品、礼品与定制、小圈子商品、专业服务、情报/数字商品及其他实际发现的交易；不预设卖课或AI最优。

成熟实名名人、权威作者、高粉 newsletter 仅作为**反例与对照组**，不能因为商品定价公开、资料容易抓取就占据主要样本。必要时保留“有形象却没交易”的失败样本，避免幸存者偏差。

重点不是评头像或收集名言，而是**同一账号至少看数条实际内容、商品和公开买家行为，把它们联系起来**。有对外联系方式不等于有人付款；有高销量不等于因为人设。

## 五、最终交付

让用户能够看见：哪个真实账号采用怎样的一套商业角色、哪些线索促使哪类人可能形成判断、流量从哪里来、实卖什么、客单/交付怎么回事、普通人可借鉴哪一环、哪些成本和利益不可复制。并能把A确认的某个商品×人群转成**可实测、可交付的人设方案**，而不是一篇高级的心理学综述。

首批合格案例必须供用户审阅方向，不能几十分钟把20个名人的主页和收费页抄成“20套完整人设系统”。没有进入App、没有看作品和评论时，应请求用户安全配合，标明未核；不要用国外公开网站替代中国封闭平台。

用户已有多账号设想：可研究一个账号一种清晰角色的多账号矩阵，但需比较矩阵重复获客、维护成本与产品协同，不默认越多越好。
