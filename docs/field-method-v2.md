# 人设账号田野逆向 SOP v2

目标：**现场查清“某类人 → 看到某种精心设计的形象 → 产生哪些信任推断 → 被引向哪个商品 → 为什么可能下单”**。不要再以名人成功学或商品价格表代替图文与交易研究。

## 1. 找号：先从商品或真实客户入口反查

三路独立发现：
1. **买方问题**：小红书、闲鱼、淘宝/天猫、抖音的公开求购、问价、笔记评论、差评、晒单；追他最终看到什么角色、什么产品以及为何选择。
2. **商品/店铺**：出现销量信号的定制、高客单、小圈子产品；从商家页面追运营账号、营销笔记、主页、评论、跳转和私域引导痕迹。
3. **内容人设**：低调、不露脸、有一致视觉和语气、展示资源/品位/专业气质的账号；反追他卖什么、谁在买、在哪买。查不到产品的列为“内容人设”不计商业化完成案例。

平台访问受阻就写明真实阻塞，并请用户在Work安全登录/提供页面；不利用绕过访问控制的方法替代。

## 2. 一案必须实看内容与页面

至少观察账号主页及**多篇代表性内容**，优先覆盖吸粉内容、建立权威/资源感内容、软性承接内容、明确商品或询单内容；可按实际账号节奏取约6–10篇，不为凑数复制同款。记录发布时间、配图/首图与标题、段落结构、语气、内容中的选择性展示、公开互动和评论者关注点。

再追至少一个实际商品/套餐或报价入口；如有可见销量、买家反馈、实物作品/定制案例或付款前结账，则注明源和时间。只看自我介绍、抽象价格与标签，**不能称“完整研究人设形成机制”**。

## 3. 让“潜意识觉得他厉害”变成可分析的变量

逐项写 **可见线索 → 用户可能形成的判断 → 这种判断缓解哪一个具体购买顾虑 → 哪个商品因而可能受益**。

可检查的线索包括：
- 主体角色：专业买手、资源组织者、审美主理人、隐身工作室、行业观察者、精选品牌等。
- 视觉语法：取景、材质、配色、留白、真实作品、环境与道具；对信息真实性和版权单独评估。
- 文案语法：用行业词解释价格、拒绝不合适客户、提出自己的判断、分层产品、限定承诺、选题连续性、邀请方式。
- 关系与稀缺暗示：筛选机制、排期、合作类型、样品/案例展示、圈层语境；是否为卖家自己声称，还是公开买家反馈支持。
- 用户侧反应：评论是在夸有钱、问货源、求入群、问价格还是实际购买？**互动不能自动等价为认同或成交**。

不要替受众编“他一定觉得这是大佬”；当缺少实测访谈时只写合理心理假说，并给出其他可能解释（产品本身、价格、投流、专业能力、库存或偶然推荐）。

## 4. 把成交链画清楚

具体某篇内容/账号 → 主页或商品点击 → 标价或询单 → 支付前页面/交易留言 → 交付方式/售后 → 复购触点。

每一箭头明确 **实走/页面可见/运营者自述/推断/无法访问**。同一账号多个SKU不要凑成某一条“从低到高自动升级的转化漏斗”。无法接触私域可说明仅见到引导而非完成交易；需要测试或购买时提出单独授权申请。

研究用户为什么要为这个人付钱，而不是为同价商品另一卖家付钱；比较同类普通账号和失败或低转化线索，寻找真正的信任差异。

## 5. 可复制性：把“包装”变成可执行而非虚构

拆成可设计的角色定位、栏目、照片/作品获取路径、内容系统、商品图与信息架构、免费/付费承接入口、售后说明、视觉标准。每个元素都要能在实际交付条件下维持一致，不能靠一次生成图片维持所有长期真实业务细节。

匿名/品牌化合理，创作精心包装合理；**不得用伪造资质、豪车财力事实、编造客户订单、虚假好评去充当验收证据或试验方案**。这是商业诚信、平台封禁、售后纠纷与长期信任约束，不替代对说服力的正常研究。

## 6. A/B 交叉

把一条证据充分的 B 账号映射到 A 的商品/人群；若A尚无对应需求证据，B只输出“值得A核的商业线索”，不能宣布产品盈利。

B可优先从A的候选行业找号，不必永远等A完成。对每一种候选可形成“商品和客户疑虑 → 几种可信角色 → 可观察的内容机制 → 可实测的小范围方案”，实际发布前需获授权。

## 7. 节奏与失败条件

首批 **3–5个真正符合条件的中国商业人设号**，每案实际看内容、商品、承接与至少一个竞争/普通对照，先发用户审阅，不是直接产20案。

用户审核方向后扩到约10–15个**合格**对象，深拆至少3个不同交易逻辑的账号；不足则说明哪些平台/形态被阻挡，不能用成熟实名专家凑数。最终选1–2个基于A客群/产品的具体可测试模型；如果A尚无候选，保留待设计状态。

每一个入库案例必须有新信息；对同质账号增加数量不能提高完成度。只有价目表无内容证据、只有网红无商品、只有视觉审美无交易入口的，不算完成案例。
