# 研究方法与证据标准

观察日期为 2026-10-19。价格和入口随时可能变化，交易前须以相同商品的最终页面复核。本轮不购买、不联系作者、不申请试用；没有付费内容的实际使用体验。

## 2026-10-19复审的共用边界

固定提醒集中在此，不在20案反复抄写：同一经营者多个网页不构成多份独立成交证据；全库未由研究者付款/体验付费交付，也未核净利润。没有同范围替代与买方理由，不归因为人设溢价。各案只写独有事实与断点。

首版案例是商业入口目的抽样，多数未分析具体作品，不能全称已完成系统深拆。本轮仅B06/B15补到具体内容/作品。B15的T1来自历史模板用户自述，P3来自另一商品年会员的付款前表单，不能合并成一笔订单链。旧完整性索引只对应旧保存件；本轮新增来源就近附正文，原始文本/截图另在本机私存，不宣称全部纳入旧索引。

四类行动暂判沿用户口径：已有理由继续深入、值得做一次小核查、仅保留为启发、当前暂缓或排除某一种具体做法。它们区别下一步，不是成功分数。当前预算、工时、能力和资源未知不代填，技能可学与资历/渠道/资产分别看。上传、发布、接触客户与交易按具体动作授权。

## 如何选案例

从中文付费专栏/编程社区、专业订阅、设计服务、数字产品和工具创始人中目的抽样。优先主体能关联到销售入口、可用文字或作品传递能力、能看到交付边界的账号。不是按粉丝榜抽样，也不代表平台全貌或总体成功率。

先由三个独立研究单元读一方来源，总协调复查动态中文页面、冲突价格和典型结账条件。现成案例只是发现入口，关键判断回到作者、产品、支付平台或规则页。找不到的环节记断点；不为凑整数，把停售商品当仍在卖。

海外独立站公开价格和条款更容易读取，因此样本偏向数字产品、英语受众及拥有既有声誉的人。国内私域咨询、非公开报价、平台推荐流和线下成交覆盖有限。不能由这批案例推出“知识付费最好做”或“做个人 IP 必须卖课”。

## 两条证据轴

交易路径与成交实证独立记录，不能用一个含糊的“成功”评级合并。

| 路径层级 | 已看见什么 | 不能据此推出什么 |
|---|---|---|
| P1 | 主体、内容和公开商业入口 | 当前可付款、真实有人购买 |
| P2 | 当前商品、收费单位、交付与条款可读 | 结账金额与实际履约已核 |
| P3 | 走到无需支付的购买/结账页面，核对商品与条件 | 已完成下单或付款 |
| P4 | 真实授权订单与交付凭证 | 本轮没有此项 |

| 成交实证 | 含义 |
|---|---|
| T0 | 无独立成交证据；仅商品、价格、卖方好评/规模说法 |
| T1 | 平台公开统计、公开买方自述/售后回应或广告交付样本；仍非核账 |
| T2 | 可核订单和履约/买方访谈相互支持；本轮没有此项 |

只有同主体的公开路径才能连线。跨平台跳转说明用途，但登录后的步骤依平台文档注明“规则说明”，不能声称已实走。退款必须区分现金、平台余额、审核条件、时间、商品例外；不同课程/订阅不得借用彼此条款。

## 观察、推断、反证

案例的事实引用最靠近对应出处；心理分析和溢价解释明确作为假设。无同类替代品、支付者理由或控制比较时，只能说“价格较高/分层收费”，不能归因为人设溢价。还要保留免费替代、条款冲突、退款摩擦、旧页残留和并非内容获客的解释。

视觉只描述已实看页面；内容分析选具体公开样本，不以自我介绍代替内容。读者数是平台展示值，可能含历史价格、赠送、兑换与退订差异，禁止“价格×读者数=收入”。创始人收入自报也不等于利润，更不说明新人能复制。

## 可做性

分别评估角色可信依据、交付能力、获客成本、资金、维护与售后负担。优先提取能用真实小作品证明的狭窄能力；不要让新人先扮演资深专家，再去补能力。AI 的输出仍须人工验证，专业服务不能以模板替代真实验收。

公开来源列表为复查入口，不是全量网页备份。私有档案保留查询/抓取结果及 SHA-256；公开索引只留相对档案标识、来源 URL、观察日期与简短事实。独立验证者可直接复访公开 URL；无法复访时应降低该判断，不凭哈希证明内容正确。
