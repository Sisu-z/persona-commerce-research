# 研究方法与证据标准（B v2）

**本文件服务 [Issue #4](https://github.com/Sisu-z/persona-commerce-research/issues/4) 新任务。** 首版20案属于历史，对照与成交信号分级可以继续用；旧的成熟中文专栏/国外Newsletter目的抽样，**不再作为当前主样本选择规则**。优先读 [项目宪章](charter.md)、[真实账号逆向SOP](field-method-v2.md)、[验收](acceptance-v2.md)。

## 一、选择与亲访

从中国实际可访问的平台查匿名/不露脸/弱实名**商业账号**，筛选其角色经营的强度及真实SKU/付费咨询入口，不以是否实名露脸简单代替完整判断。先看内容：账号主页、数篇代表图文或视频、可见评论/公开买家反馈、商品/咨询路径，而不是只保存自我介绍与价格。

记录每个来源的观察日期、检索入口、登录/页面可见限制。研究者需要解释哪些视觉元素、叙事与措辞使特定受众可能形成某种印象，以及这些印象对应的购买风险。**受众信念与人设溢价是可检验假说，不能等于研究者自己的观感。**

同类普通账号和有形象无明显成交的账号应保留，用于比较；不能只看最有名或最好看的号。用户亲自登录的平台可读取公开页面，但不进入私人聊天、收件箱、支付或权限受限数据。

## 二、公开交易强度：保留双轴，拒绝错配

| 观察路径 | 含义 | 不意味着 |
|---|---|---|
| P1 | 内容、主体与当前公开商业入口连得上 | 有人付钱 |
| P2 | 某SKU/服务的价款、交付与条款可核 | 最终订单金额、实际履约 |
| P3 | 研究者看到无需付款前的购买/结账页面 | 完成了付款 |
| P4 | 经用户授权可核真实订单、收货/交付 | 自动存在净利润或人设因果 |

| 成交信号 | 含义 |
|---|---|
| T0 | 只有卖方上架、价格、卖方自评，缺独立成交信号 |
| T1 | 平台销售展示、独立公开买方自述、买后评价、公开付款/使用线索；口径注明，非核账 |
| T2 | 可核付款与交付/独立买方过程相互支持；首版没有T2，后续若有须合法授权 |

新增研究再补两列：**H（人设证据）**，是否实看内容并分析暗示链；**F（漏斗证据）**，从公开内容到具体SKU/询单有几段是实看。P3/T1也不能替代H/F。

不同商品、历史促销、平台币、区域币种、登录前0元和退款条款不得拼成一单。对交易外推与营销包装分别保留替代解释。

## 三、市场解释

事实层：商品、页面、交付承诺、公开评论与图文细节。推断层：消费者潜意识里的专业/资源/品位印象；可能因而信任；可能愿意支付的溢价。未知层：是否付费、为何选择、私域复购、实际毛利、包装是否有因果贡献。

特别检查：产品本身质量、熟练经验、平台流量推荐、早期人脉/受众、广告预算、特殊供应商是否已经足以解释成交。缺同规格对照和买方选择理由，不得把“贵”写成“人设提高了利润”。

不能因账号不披露个人生活就判低可信；也不能凭图文暗示推定经营者真实财富、学历或合作名单。分析允许记录这种暗示如何影响决策，商业实验不能提交伪造事实性证明。

## 四、首轮取证与研究可复核性

每案至少有主体/商品的干净链接、几条代表性内容来源、观察日期、公开评价或评论摘要、当前可见套餐或标价、主要CTA、至少一条替代/竞品线索、交易路径的断点、可复制部分及依赖真实履约的部分。

实际现场截图、完整评论、支付动态页面、个人账号信息不进入公开Git。仓库只保留去身份的必要摘要和干净链接，用户许可的私有材料与公开索引分开。私有哈希只能证明保存件一致，不能证明成交真实。

首批3–5案要先让用户审阅，方向正确后再拓展。没有实看图文商品链的档案不可升级为完整人设研究；无法进入中国关键App时提出配合请求，不能用英文公开网站代替。

## 五、归档与协作

旧 [cases/README](../cases/README.md)、[2026-10-19报告](../reports/synthesis.md)都是历史分析材料；首版 [data/cases.jsonl](../data/cases.jsonl) 的 category 与 P/T 仅适用于原始样本，不能自动表示v2合格。

A负责找真实买家/利润/上游与入场；B负责品牌人格形成、流量信任与商品承接。相互回传链接与可核命题，不能通过相互引用把推断变成独立验证。C只有经用户审定才接收方法论。

文档与代码检查只验结构；实际是否研究出了符合目标的人设商业化模式，由 [v2验收](acceptance-v2.md)决定。
