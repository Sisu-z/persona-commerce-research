# B-002 执行方案：先找真实匿名变现，再设计人设

[唯一状态源：GitHub Issue #4](https://github.com/Sisu-z/persona-commerce-research/issues/4)。本文件只定义工作内容和验收，不另维护独立任务状态。

## 第一轮：3–5个不同的具体账号，给用户看实物证据

在小红书、闲鱼、淘宝/天猫、抖音等真实入口，从付费商品、买家求购和角色内容反查账号；尽量不要找实名网红大号。优先：专业选品、非标准定制、资源渠道、审美主理、特定知识/数字产品、有作品的隐身工作室；发现其他有意思的应立即纳入。

每案读约6–10篇有区别的代表性内容，并记录主页、图片/文案线索、公开受众反馈、商品与可见交易入口。说明定位隐含什么能力、为何吸引具体付费人群、竞争或普通账号怎样卖同类商品。第一批全是课程大V/Newsletter或只有主页+价目表，判方向失败，需重采。首批给用户审阅后才系统扩样。

## 第二轮：深度拆解与横向比较

筛到10–15个合格主体（不能拿不合格补数），深拆3个不同商业化方式（可有一例失败）。按 [案例模板](../templates/persona-deepcase-v2.md)写消费者画像、商品与报价、实际内容信号、内隐信任、内容→商品→付款前入口、由谁履约、反证、普通人能否复制。着重寻找小号、小团队或新进入者，而非复制十年经验。

## 第三轮：结合 A 做方案，不预设卖什么

A已验证有真实需求且适合人设获客，则反向写出1–2组 **【具体付费人群×商品×商业角色×内容矩阵×交易承接】**，提供可操作的账号与内容草案，以及最低交付要求、验证指标和止损条件。

A仍无合格商品时，B可继续整理具有明确交易入口的独立案例，但**不得因为会造人设就凭空发布商品或宣称有生意**。回传给 A 的是可查账号、产品和客户线索，不是心理学通用理论。

## 新任务不包含什么

不重做20位成熟创作者销售价目表，不顺着A历史Excel剪辑小单做演示，不为填满字段反复写“未核溢价”。材料、页面和推断须明晰，重要断点明确；登录/访问受阻请用户配合。市场联系、建号、发帖、广告、购买、收款均另获授权。
